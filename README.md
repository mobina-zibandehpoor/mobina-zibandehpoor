## 👋 About me

I work where **mechatronics**, **computer vision**, and **cognitive science** meet.

I am an M.Sc. mechatronics researcher in the Biomechatronics Laboratory at **K. N. Toosi University of Technology**, supervised by Dr. Mehdi Delrobaei. My thesis built a non-invasive framework for assessing spatial navigation from **vision-based pose estimation** and **IMU motion capture**, with machine learning for feature extraction and interpretability. Complementary work uses **EOG-based eye tracking** (Leiden Navigation Test) to broaden multimodal cognitive assessment.
